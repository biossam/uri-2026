# 우리들의 2026 ✎

칠판에 분필로 쓰듯 실시간으로 글이 나타나는 하루 행사용 방명록이에요.

| 주소 | 화면 |
|---|---|
| `/?c=행사코드` | 앞 화면 (TV·프로젝터에 띄우기, F 키 전체화면) — 관리자 화면의 '앞 화면 열기'로 여세요 |
| `/letter.html?c=행사코드` | 학생 글쓰기 (앞 화면 QR에 코드가 들어 있어요) |
| `/admin.html` | 관리자 (숨김·삭제·CSV 저장·전체 삭제) |
| `/?demo` | 예시 글로 미리 보기 |

## 개인정보 보호
- **행사 코드**를 아는 사람만 칠판을 보고 쓸 수 있어요. 주소만으로는 볼 수 없어요.
- 글과 사진은 **쓴 날부터 `RETAIN_DAYS`일(기본 3일) 뒤 자동으로 지워져요.**
- 전화번호·주소·이메일처럼 보이는 글은 선생님 확인 뒤에 공개돼요.
- 글쓰기 화면에 무엇이 남는지, 누가 보는지, 언제 지워지는지 아이들 말로 안내해요.
- 사진은 휴대폰에서 다시 압축해 올려서 촬영 위치 같은 정보(EXIF)가 빠져요.
- QR은 서버가 직접 그려요 (바깥 QR 서비스를 쓰지 않아요).
- 학생 사진·이름을 게시할 때는 보호자 동의가 필요할 수 있어요. 가정통신문에 넣거나 `PHOTOS=0`으로 사진을 끄세요.

## 행사가 끝나면
1. 관리자 화면에서 **⬇ CSV 저장**
2. **🔒 방명록 닫기** — 켜진 화면이 모두 꺼지고, QR을 찍어도 아무것도 못 봐요
3. 다음 행사 전에 **🧹 전체 삭제** (새 코드가 만들어져요)

코드가 밖으로 퍼졌으면 **🔑 코드 바꾸기**를 누르세요. 옛 QR은 바로 못 써요.

## 규칙
- **한 기기(브라우저)에 글 1개.** 처음 쓰면 그 기기에 '수정 열쇠'(쿠키)가 저장되고, 그 뒤로는 고쳐 쓰기만 돼요.
- 욕설이 의심되는 글, 사진이 붙은 글은 **선생님이 관리자 화면에서 '확인·공개'를 눌러야** 칠판에 써져요.
- 관리자 화면의 **삭제+차단**을 누르면 그 기기에서는 다시 쓸 수 없어요.
- 학교 태블릿처럼 여럿이 쓰는 기기는 글을 쓴 뒤 **"친구와 같이 쓰는 기기예요 (연결 끊기)"**를 눌러요. 다음 친구가 내 글을 보거나 고칠 수 없어요.
- 관리자는 비밀번호로 로그인하면 12시간짜리 열쇠를 받아요. 같은 와이파이에서 누가 비번을 틀려 로그인이 잠겨도, 이미 들어와 있는 선생님은 그대로 쓸 수 있어요.

## Render 환경변수
| 이름 | 뜻 | 기본값 |
|---|---|---|
| `ADMIN_PW` | 관리자 비밀번호 — **8자 이상이 아니면 관리자 화면이 잠겨요** (이 코드는 공개돼 있어서 쉬운 비번은 위험해요) | 없음 |
| `EVENT_CODE` | 행사 코드 (정해 두면 서버가 다시 켜져도 그대로) | 자동 생성 |
| `RETAIN_DAYS` | 며칠 뒤 자동 삭제 (0이면 끄기) | 3 |
| `REVIEW_ALL` | `1`이면 모든 글을 확인한 뒤 공개 | 꺼짐 |
| `PHOTO_REVIEW` | `0`이면 사진도 바로 공개 | 켜짐 |
| `PHOTOS` | `0`이면 사진을 아예 받지 않음 | 켜짐 |
| `BANNED_WORDS` | 더 거를 낱말 (쉼표로 구분) | |
| `MAX_CHARS` | 글자 수 (public/config.js 와 같게) | 80 |

## Render 설정
- 환경변수 `ADMIN_PW` 에 관리자 비밀번호를 넣어 주세요. (없으면 1234)
- 무료 서버는 15분 동안 아무도 안 쓰면 잠들어요. 행사 시작 몇 분 전에 앞 화면을 먼저 열어 두세요.
- 무료 서버는 다시 시작되면 글이 지워질 수 있어요. **행사가 끝나면 관리자 화면에서 CSV로 받아 두세요.**

## 행사마다 바꾸기
`public/config.js` 의 제목·부제·글자 수만 바꾸면 돼요.
